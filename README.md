# Swing Coffee ☕

一个纯静态的咖啡点单动画网站：选择一款咖啡，观看它按真实制作步骤在透明冷杯中完成 —— 落冰、注奶、注入浓缩、分层晕染、盖盖出品。

无任何依赖，纯 HTML / CSS / JavaScript（SVG + requestAnimationFrame）。

## 运行

直接用浏览器打开 `index.html`，或起一个静态服务：

```bash
python -m http.server 4316
```

然后访问 <http://localhost:4316>。

## 四款饮品

| 饮品 | 风格 | 制作流程 |
| --- | --- | --- |
| Vanilla silk · 香草丝绒拿铁 | 浓缩浮顶 + 香草籽 | 落冰 → 注奶 → 浓缩 → 晕染 → 盖平盖 |
| Choco chips · 巧克力碎冰沙 | 挂壁酱 + 奶油拱盖 | 挂壁酱 → 满杯注入 → 奶油 → 撒碎 → 盖拱盖 |
| Caramel cloud · 焦糖云朵玛奇朵 | 挂壁焦糖酱 | 挤酱 → 落冰 → 注奶 → 浓缩 → 晕染 → 盖平盖 |
| Matcha mist · 抹茶轻雾拿铁 | 抹茶浮顶 + 抹茶粉 | 落冰 → 注奶 → 抹茶 → 晕染 → 盖平盖 |

## 结构

- `index.html` — 页面与主舞台 SVG（杯体、分层、盖子、水流）
- `style.css` — 石纹光影背景、底部选择面板、胶囊按钮
- `app.js` — 饮品配置（`DRINKS`）、卡片插画生成、分步动画状态机（时长见 `DUR`）
- `design/` — 设计稿工作文件（杯型画板与分步分镜）

## 自定义

在 `app.js` 顶部的 `DRINKS` 数组中增删口味：`layered` 类型走拿铁流程，`blended` 类型走冰沙流程；分层配色、挂壁酱、香草籽/抹茶粉等均为可选字段。
